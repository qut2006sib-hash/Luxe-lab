# LUXE Lab

نظام مستقل لإدارة مخبر طبي واحد، مبني كـ **Modular Monolith** باستخدام
React وTypeScript وtRPC وDrizzle وMySQL.

## نطاق الإصدار الأول

- سجل المرضى.
- دليل التحاليل ومعاملات النتيجة والوحدات والمجالات المرجعية.
- إنشاء طلب تحليل من اختبار واحد أو عدة اختبارات.
- إدخال النتائج تدريجيًا ثم اعتمادها وطباعتها.
- إنشاء ذمة وفاتورة وقيد يومية متوازن لكل طلب.
- تحصيل كامل أو جزئي وربط الدفعة بالفاتورة.
- عزل كل البيانات بحسب المؤسسة وصلاحيات المالك والمحاسب.
- سجل تدقيق وتفاؤل بالتزامن لمنع الكتابة فوق تعديل أحدث.

المشروع مستقل عن **LUXE Real Estate** من حيث المستودع والتشغيل وواجهة API.
النواة المحاسبية محفوظة كحدّ نطاق مشترك في التصميم، ويمكن لاحقًا إصدارها
كحزمة داخلية ذات إصدارات بدل نسخها يدويًا بين المنتجين.

## البنية

```text
client/                       واجهة المخبر العربية
server/modules/lab/           المرضى والتحاليل والطلبات والنتائج
server/modules/accounting/    دليل الحسابات والذمم والقيود والمدفوعات
server/modules/organizations/ المؤسسة والصلاحيات
server/platform/              مهام الخلفية والتهيئة المحلية
drizzle/                      المخطط والترحيلات
```

## التشغيل على Ubuntu/Linux

المتطلب الوحيد هو Docker Engine مع Compose plugin:

```bash
cp .env.local.example .env
docker compose up --build -d
curl --fail http://127.0.0.1:3000/health/live
curl --fail http://127.0.0.1:3000/health/ready
```

ثم افتح <http://127.0.0.1:3000>. وضع المعاينة المحلي يسجّل الدخول بحساب
مالك تجريبي تلقائيًا، ولا يعمل إلا مع `NODE_ENV=development` و
`DEPLOYMENT_ENV=local` وعلى loopback.

## قواعد مالية ملزمة

1. كل قيد مرحّل متوازن ومدين/دائن لا يساويان صفرًا معًا.
2. تستخدم الأموال قيمًا عشرية ثابتة لا أرقام JavaScript العائمة.
3. المستند المرحّل لا يُحذف ولا يُعدّل بصمت.
4. لا تتجاوز الدفعة الرصيد المتبقي للمستند.
5. كل عملية آمنة لإعادة المحاولة عبر idempotency key ومصدر نطاقي.
6. العملة في الإصدار الأول هي عملة المؤسسة فقط.

## التحقق

```bash
pnpm install --frozen-lockfile
pnpm check
pnpm test
pnpm build
```
